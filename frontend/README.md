# Frontend

Blade + Livewire UI work governed by `DESIGN.md` and `docs/frontend.md`.

## User- and model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[redesign-from-template](./redesign-from-template/SKILL.md)**: Redesign a Blade/Livewire page from an external template, mockup, or pasted HTML/image/URL. Template is the base only; keep needed content, skip the rest; reuse existing Blade components, expanding or creating only after proposal.
- **[redesign-from-template-triage](./redesign-from-template-triage/SKILL.md)**: Same base, but nothing unmatched is silently skipped — every unused template section is triaged with you as skip, placeholder (`<x-empty>` shell, no fake data), or implement properly (with confirmed scope).
